# 基础方法论索引

本目录承载跨领域、跨技术栈、跨项目类型复用的上位方法论。

它解决的不是“某个领域怎么做”，而是“设计、建模、验证和取舍应遵循什么底层思维结构”。

建议按问题类型读取：

- 结构、不变量、状态机、图、集合、依赖：看 `discrete-math-and-structural-thinking.md`
- 随机性、实验、显著性、误差、A/B：看 `probability-statistics-and-experimental-thinking.md`
- 向量、矩阵、变换、最优化、数值稳定性：看 `linear-algebra-optimization-and-numerical-thinking.md`
- 对称性、群作用、代数结构、组合与生成：看 `algebraic-structures-and-symmetry-thinking.md`
- 工匠精神、边界克制、设计审美、可逆变更：看 `architecture-and-design-craftsmanship.md`
- 状态建模、生命周期、事件驱动、形式化约束：看 `modeling-and-state-machine-thinking.md`
- 失败、恢复、幂等、隔离、可靠性：看 `failure-and-reliability-thinking.md`

长程 Agent 的检查点、对照评测与受约束自改进试点：见 agent-rsi-engineering.md。

这些文档默认不会直接取代领域文档，而是作为领域文档和设计评审的上位约束来源。
