# 项目类型 Profile 索引

本目录承载“项目类型组合约束”。

与 `domains/` 的区别：

- `domains/`：描述某个专业领域的通用约束
- `profiles/`：描述某类项目默认需要组合加载哪些 foundations / domains / templates

建议用法：

- 桌面产品：先看 `desktop-application.md`
- 后端服务：先看 `backend-service.md`
- 嵌入式系统：先看 `embedded-system.md`
- 机器学习系统：先看 `ml-system.md`
- 安全研究项目：先看 `security-research.md`
