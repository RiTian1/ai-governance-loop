# 原生安全运行时项目组合约束

适用于包含原生代码、安全语义、策略执行引擎、多运行时集成和交付制品的项目。

## 默认组合

- foundations:
  - architecture-and-design-craftsmanship
  - modeling-and-state-machine-thinking
  - failure-and-reliability-thinking
- domains:
  - base-runtime
  - security
  - automation
  - devops-ci
  - documentation-and-api

## 重点问题

- 规则语义是否跨集成保持一致
- 第三方源码偏移是否可追踪
- 原生运行时边界是否清晰
- 产物构建与回滚路径是否明确
- 证据是否足以支撑安全类改动交付
